# 도지뿡

도지건의 장풍 버전. 총 버전(`도지건/`)과 분리된 2D 2등신 캐릭터 대전 프로토타입입니다.

화면 콘셉트는 카키색 전장, 황동 금속 프레임, 두꺼운 픽셀 HUD와 스캔라인을 사용하는 레트로 밀리터리 아케이드 스타일입니다. 특정 작품의 아트 에셋은 사용하지 않고 픽셀 렌더링과 자체 UI로 구성했습니다.

현재 맵은 동양식 정원 아레나로 교체되어 바위, 소나무, 대나무, 단풍, 돌길, 연못이 배치되어 있습니다. 플레이어와 적은 각각 기본 자세와 양손을 옆구리에 모은 충전 자세의 투명 전신 픽셀 스프라이트를 사용합니다.

장애물은 배경과 구분되는 검은 외곽선의 동양식 돌담/목재 캡 에셋이며, 장풍에 맞으면 피격 플래시와 함께 짧은 넉백 및 픽셀 파편 모션이 발생합니다.

## 규칙

- 탄환과 장전이 없습니다.
- 마우스 왼쪽 버튼을 누르고 있는 동안 장풍을 차징합니다.
- 정지 상태에서만 차징 게이지가 올라갑니다.
- 차징 중 이동하면 게이지가 빠르게 감소합니다.
- 버튼을 놓는 순간 현재 차징 단계의 장풍이 발사됩니다.
- 짧게 쏴도 장풍은 중간에 사라지지 않고 벽이나 아레나 끝까지 날아갑니다.
- HP는 100 기준입니다.
- 피해량은 차징 비율에 따라 최소 8부터 최대 55까지 연속적으로 증가합니다.
- 오래 차징할수록 장풍이 더 빠르고 오래 유지되며 피해량도 커집니다.

## 실행

프로젝트 루트에서 다음을 실행한 뒤 `http://localhost:8000/도지뿡/`을 엽니다.

```bash
python3 -m http.server 8000
```

조작은 `WASD 이동`, `마우스 조준`, `왼쪽 버튼 홀드 차징 / 릴리즈 발사`입니다. `SPACE`로 점수를 초기화할 수 있습니다.

- `assets/player-charge.png` — 플레이어 양손 모으기 충전 전용 스프라이트
- `assets/enemy-charge.png` — 적 양손 모으기 충전 전용 스프라이트
- `assets/eastern-garden-bg.png` — 동양식 정원 아레나 배경
- `assets/energy-wave.png` — 꼬리 광선·화살촉·전기 아크가 있는 장풍 효과
- `assets/eastern-wall.png` — 돌담과 목재 캡으로 구성된 동양식 장애물
