# 몽진 1.0.0 (빌드 51)

## iPhone App Store 재심사본

- 기존 심사 빌드 5를 PvP 업데이트 빌드 51로 교체합니다.
- 빠른 대전에서 iPhone 사용자가 운영 서버를 통해 실시간으로 매칭됩니다.
- 랜덤 매칭, 친구 대전, 익명 프로필과 전적 동기화를 지원합니다.
- 심사 중 상대가 없으면 15초 뒤 로컬 대전으로 전환되어 핵심 플레이를 계속 확인할 수 있습니다.

## 앱인토스 iPhone·Android 빌드

- 사용자가 지정한 `bowfin/mongjin.ait` 최신본을 기준으로 만들었습니다.
- iPhone과 Android가 같은 PvP 서버에서 서로 매칭되고 착수·턴·말 수를 동기화합니다.
- 토스 로그인이 없어도 서버가 발급한 익명 사용자로 바로 랜덤 대전에 참여할 수 있습니다.
- 채팅은 제공하지 않습니다.
