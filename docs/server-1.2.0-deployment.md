# 몽진 1.2.0 서버 배포

이 변경은 운영 `main`의 빠른 대전 재접속, 턴 시계, 친구 재대국과 공식 봇을 유지하면서 플랫폼 공통 대회, 신청, 우편함, 만다꼬 연습, 알림 전송과 자동 일정 선정 기능을 추가한다. 모바일 화면과 스토어 출시는 별도 작업이며 이 서버 배포에 포함하지 않는다. 합의한 릴리스 메타데이터는 1.2.0+73이다.

## 초기 운영 설정

`MONGJIN_PUSH_ENABLED=0`, `MONGJIN_MATCH_PUSH_ENABLED=0`으로 시작한다. 자동 일정 정책도 기본 비활성이다. 공급자 키 등록만으로 기기 수신이 확인된 것으로 간주하지 않는다. 허용된 실기기에서 알림 수신과 대회 진입을 검증한 뒤 발송 플래그와 자동 정책을 활성화한다.

토스 mTLS 파일은 Render Secret Files의 `/etc/secrets`에 저장하며 개인키·관리자 토큰을 Git에 넣지 않는다. Expo의 APNs·FCM 키는 Expo 프로젝트에서 관리한다. 대회 알림은 등록자와 동의자에게만 보내고 모집 공지는 우편함에 게시한다.

첫 대회만 활동 데이터 부족 시 토요일 21:00–22:00 KST, 최소 신청 20명을 초기 기준으로 쓴다. 이후에는 실제 이용 기록으로 정한다. 활성화 전에 `GET /admin/tournament-scheduler/dry-run`을 확인하며 기존 미래 일정과 중복되는 대회를 강제 생성하지 않는다.

## 검증

서버와 공유 소스 타입 검사, 전체 테스트 777개가 통과했다. 별도의 격리 PostgreSQL 검사에서도 DB 의존 9개를 포함한 29개가 모두 통과했다. 실제 WebSocket 회귀 검사에서 대회 상태 요청 후에도 일반 빠른 대전 재접속과 착수가 이어진다. 이 결과는 Render 시작, 운영 저장소, 공급자 접수 및 실기기 수신 검증을 대신하지 않는다.

배포 후 `/health`, `/tournament/status`, 관리자 인증, 정책 비활성 상태와 일정 dry-run을 확인한다. 운영 데이터와 신청·점수 기록을 초기화하지 않는다.
