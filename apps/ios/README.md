# 몽진 iOS

웹/앱인토스 버전과 같은 규칙의 네이티브 SwiftUI 앱입니다. **빠른 대전**은 접속 중인 상대를 먼저 찾고, 매칭이 안 되면 비슷한 레이팅의 기보(고스트)와 둡니다.

```
ios/
  Mongjin.xcodeproj   # Xcode에서 이 파일을 엽니다
  Mongjin/            # SwiftUI 화면
  Sources/MongjinCore # 규칙·AI·고스트 엔진 (웹 src/core 와 동일)
  Tests/              # 엔진 단위 테스트
```

## 실행

1. `ios/Mongjin.xcodeproj` 를 Xcode로 엽니다.
2. 팀(Signing)만 본인 계정으로 맞춥니다.
3. iPhone 시뮬레이터 또는 기기에서 Run (⌘R).

iOS 17 이상. 웹 프로젝트에 의존하지 않습니다.

엔진만 검증하려면:

```bash
cd ios
swift test
```

## 빠른 대전

1. 홈에서 **빠른 대전 → 대국 시작**을 고릅니다.
2. 15초 동안 접속 중인 상대를 찾습니다.
3. 매칭이 안 되면 레이팅이 가까운 기보가 상대가 됩니다. 기보 수가 그대로 두면 재생하고, 당신이 다른 수를 두면 가까운 합법 수로 응용하거나 즉흥으로 응수합니다.
4. 끝난 대국은 다음 빠른 대전의 폴백 상대가 됩니다.

## 그 외 모드

- **컴퓨터**: 쉬움 / 보통 / 어려움
- **같이 두기**: 한 기기에서 흑·백 교대
- 규칙·말 이미지는 웹 몽진과 같습니다 (9줄, 호위 8, 목적지 가운데 3칸).
