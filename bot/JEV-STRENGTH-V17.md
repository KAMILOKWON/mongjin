# JEV v17 조기 강제패 검증

2026-09-21. 로컬 개발 후보이며 운영은 v13이다. 앱 버전은 1.0.8(64)를 유지한다. 매칭, Elo, 게임 규칙은 변경하지 않는다.

## 문제와 변경

v16 수비형 백 개발국의 네 번째 백 착수 `m_2_3_3_2`는 기존 4ply 공통 탐색과 최대 6ply 연장에서 미확정이었다. 그러나 실제 상대 응수 뒤에는 모든 합법 수가 6ply 강제패였다. 후보 검증이 이 왕 전진의 8ply 강제패를 읽지 못했다.

v17은 공통 탐색 뒤의 미확정 후보에 한해 상대의 강제승을 최대 8ply까지 검사한다. 상대 차례에는 승리하는 응수 하나, 우리 차례에는 모든 합법 방어 수의 패배가 필요하다. 종국 판정은 기존 `src/core`만 사용한다. 시간·노드 한도로 중단하거나 종국에 닿지 않으면 미확정이며, 이를 안전이나 우리 승리로 바꾸지 않는다. 수순 정렬은 탐색 효율에만 사용하고 후보를 점수로 제외하지 않는다.

공통 탐색과 새 검사는 기존 검증 예산 3초·100,000노드를 공유한다. v17 옵션을 지정한 경우에만 이전 정적 평가 연장을 대체한다. 일반 분석의 기본 동작과 이전 기록의 재생은 유지한다. 정확한 패배 증명이 생기면 기존 강제패 제외 규칙을 적용한다. 전부 강제패이면 기존 범위 확인·한 번 재제안을 유지한다. JEV의 6개 역할·5개 우선순위·최종 Choice 구조와 최종 ID 그대로 적용 계약도 유지한다.

새 증명에는 계산 깊이, 완료 여부, 노드, 중단 사유, 종국까지의 합법 예시 수순을 기록한다. 미확정 항목의 예시 수순은 후보 한 수만 표시하며 전체 탐색 수순인 것처럼 제시하지 않는다. 재생 검사는 합법 수순·종국·증명 출처·최종 후보 제외의 일치를 확인한다. 한 가지 패배 수순만으로 강제패를 인증하지 않도록, 양성 판정은 같은 후보 순서·기록된 노드 예산·최대 8ply로 다시 계산한다. 오프라인 재검증 제한은 검색당 10초이며, 양성 판정을 재현하지 못하면 인증하지 않는다. 작은 판의 별도 전수 탐색 및 중단 테스트도 증명 알고리즘을 검사한다.

## 완료 기준

현재 개발 중이며 기력 개선·배포 완료로 보고하지 않는다. 기록된 실패 국면의 정확한 강제패를 찾아야 하고, 미확정 방어 후보를 남겨야 한다. 기능 검사 후 소스를 고정해 실제 JEV 개발 대국을 진행한다. 운영 v13과 미사용 시드 32판 비교의 기존 배포 기준도 유지한다. 기존 대국이나 개발 국면의 통과를 독립 승률 검증으로 세지 않는다.

기능 검사는 76파일 497테스트·서버 타입 검사·루트 빌드·diff 검사를 통과했다. 실제 3초·100,000노드 한도의 개발 국면 재검사에서는 1,828ms·69,458노드로 후보 5개를 검사했다. 왕 전진을 포함한 3개 후보가 8ply 강제패였고, 호위 이동과 배치 2개는 8ply에서도 미확정이었다. 전체 예산을 늘리지 않고 과거에 놓친 패배 수를 제외할 수 있음을 확인했다. 실제 대국의 승리나 독립 기력 향상은 아직 확인하지 않았다.

## 실제 개발 대국

소스 `7f4c25a`, 해시 `7617ef33d173476356afdf68a4c00532d88fc12e76074ac7260e49507bee4b73`를 고정해 수비형 백 대국을 진행했다. 기존 실패와 같은 7ply 국면에서 왕 전진 등 세 강제패 후보가 제외됐고, JEV는 남은 두 후보 중 호위 이동 `m_3_3_3_4`를 최종 선택했다. 해당 착수는 엔진의 선택 대체가 아닌 `jev-final`로 기록됐다.

이 대국은 15ply째 HTTP503이 세 번 연속 발생해 재시도 한도로 중단됐다. **정상 완료 0판·0승 0패·중단 1판**, 예정된 전술형 백은 시작하지 않았다. 11회 시도 중 착수 성공 7회·503 오류 4회·재시도 3회·API비용 0이었다. 성공 착수 지연은 6,207~12,322ms였다. 이 수치에는 실패와 재시도 대기가 포함되지 않는다. 실행 전후 엔진 파일 해시는 일치했다.

과거 강제패 선택을 막은 것은 실제 호출로 확인했지만 전체 기력 향상은 미검증이다. 중단을 패배·무승부로 집계하지 않고, 단지 더 오래 진행된 것을 기력 향상의 증거로 쓰지 않는다. 독립 32판 비교와 운영 배포는 보류한다. 원본 기보·요청·응답과 요약은 `artifacts/jev/v17/dev-white-guardian/` 및 `development-summary.json`에 보관했다.

대국 종료 후에는 착수 정책을 변경하지 않고 기록 검증만 강화했다. v17 원본 11건과 v16 원본 11건을 새 검사로 다시 검증했고 모두 통과했다. API 실패가 최종 후보 제외 단계보다 먼저 발생한 불완전 기록도 허용하되, 존재하지 않는 증명이나 후보 제외를 완료된 것으로 취급하지 않는다. 합법적인 패배 수순을 강제패로 위장한 기록, 증명 삭제, 후보 재포함과 출처 불일치를 거부하는 검사를 추가했다.

최종 검사: **76파일 503/503테스트, 서버 타입 검사, 루트 빌드, diff 검사 통과**. 기록 재검증 22/22건도 통과했다. 초기 감사 테스트의 오류 분류 및 과거 정책용 fixture를 수정한 후 전체 검사를 다시 완료했다. 기능 및 특정 전술 결함 수정은 검증됐고, 승률 개선과 운영 배포는 여전히 미완료다.
