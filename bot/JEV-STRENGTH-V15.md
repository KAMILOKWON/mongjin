# JEV v15 기력 개선 후보

2026-09-21. 로컬 개발·대국 검증 중이며 운영은 v13을 유지한다. 앱 버전 1.0.8(64), 매칭 정책과 운영 Elo는 변경하지 않는다.

## 고친 문제

v14 개발 대국에서 상대가 호위를 놓으면 왕을 전진시키거나 호위로 응수할 수 없다는 계산 결과가 있었는데도 JEV가 그 전진 수를 골랐다. 후속 국면에서는 안전한 옆걸음이 전체 합법 수에 있었지만 제안에서 빠져 후퇴만 남았다. v14 입력 압축은 모든 첫 상대 응수와 결과를 남기면서도 수순 끝의 왕·호위 위치를 생략했고, 별도 개발국은 입력 한도를 넘겨 중단됐다.

- 최종 입력을 후보별 실제 전술 결과로 정리했다. 상대의 구체적인 배치, 그 뒤 안전한 전진·옆걸음·후퇴·호위 응수 수를 해당 후보에 붙인다. 검사 미완료를 안전으로 해석하지 않는다.
- 현재 왕이 포획 위협을 받고 있으면, 다음 응수까지 완전히 검사된 안전한 왕 이동을 모두 후보에 남긴다. 옆걸음과 후퇴도 포함한다. 후보 추가는 추천이나 선택 강제가 아니다.
- 모든 첫 상대 응수와 동일 깊이에서의 왕·호위 위치·잔여 호위·다음 차례를 공통 표로 압축해 보존한다. 필요하면 중복 설명과 일부 수순 예시만 명시적으로 생략한다. 한도를 넘는 입력을 몰래 보내지는 않는다.
- 보존된 정확한 승패 증명은 최신 탐색과 분리해 원래 깊이·탐색 번호·수순을 표시한다.
- 기존 정식 규칙 계산의 호위별 전진 응수 수·감소량·즉시 포획 위협을 제안과 최종 입력에 전달한다. 계산이 불완전하면 파생값은 null이다. 선택 순위나 추천 점수는 전달하지 않는다. 경로 첫 수는 완전한 목록이 아닌 대표 예시로 표시한다.
- 몽진 왕은 주변 칸을 공격하지 않으며 서로 인접할 수 있다는 규칙을 명시한다. 정적 경주에서 누가 먼저 도착하는지도 표시하되 미래 배치가 없는 추정임을 구분한다.

JEV의 6개 역할 제안과 5개 우선순위 질문, 최종 Choice의 두 단계는 유지한다. 코드 종합 점수는 모델에게 주지 않고 최종 ID를 덮어쓰지 않는다. 기존 즉승·정확한 강제패 배제·검증 후 단일 후보 처리만 유지한다.

## 검증 상태

v14 개발 4판은 1승 2패, 입력 한도 초과로 1판 중단이었다. 초기 v15 개발 4판은 2승 2패로 모두 정상 완주했지만 흑 두 판만 이기고 백 두 판은 졌다. 33회 시도 중 3회 HTTP503 재시도가 있었고 API비용은 0이었다. 이 결과만으로 기력 개선을 확정하지 않는다. 개발 때 본 국면과 같은 상대·시드를 사용한 결과이므로 독립 검증으로 집계하지 않는다.

초기 v15 개발국 실행 후 증명 출처 분리, 정적 경주의 선착 측 표시, 호위 효과와 대표 경로 전달, 입력 크기 보완을 소스에 추가했다. 과거 개발국 최종 입력 61개를 현재 형식으로 재구성한 검사에서는 모두 26KB 이내였다. 이미 메모리에 적재된 개발 엔진과 이후 소스 변경을 구별한다. 최종 소스를 동결한 뒤 별도의 검사를 해야 하며, 실행 중인 개발국이 나중 수정까지 검증했다고 주장하지 않는다.

운영 v13과의 독립 비교는 아직 시작하지 않았다. 왕 전진형1800·수비형2000·전술형2000·변칙형1800 설정, 흑백·새 시드2개, 버전당16판/총32판의 기존 배포 기준을 유지한다. 후보10승 이상, 기준보다4승 이상 증가, 상대별2승/4판 이상, 승리→패배 회귀 최대2쌍,32판 정상 완주가 필요하다. API비용0, 실패 시도율 비증가, 성공 착수p95 15초 이하와30초 상한도 확인한다.

승률 우위나 랭킹1위를 보장하지 않으며 기준 통과 전에는 배포하지 않는다. 자세한 요청·응답·기보·개발 비교는 작업공간의 `artifacts/jev/v15/`에 보관한다.
