# 2026-09-20 랭크 봇 다양성 패치 검증

## 변경 범위

- 고정 봇 7명을 보존하고 7명을 추가하여 총 14명으로 구성한다.
- 첫 요청에서 저장된 최근 완료 상대 5명을 읽고, 이후 시작 상대를 메모리에 반영한다. Elo가 가까운 상대를 우선하되 최근에 만난 상대는 가중치를 낮춘다.
- 진출·호위·측면·전술 성향을 초반 12 ply 동안 근접 최선수 사이의 선택에만 반영한다. 순수 탐색 점수·후보 허용폭·즉시 승리와 방어 우선순위를 유지한다.
- 앱 화면, 사람 매칭 5초 설정, 게임 규칙, 기존 봇의 ID·전적·표시 Elo를 바꾸지 않는다. 새 봇 초기 Elo는 실측 실력 인증값이 아니다.
- 기존 봇 학습 자료도 유지한다. 변경된 선택 정책이 장기 실력에 미치는 영향은 운영 관측이 필요하다.

## 상대 선택 시뮬레이션

2026-09-20 조회한 기존 봇 Elo 1296/1294/1259/1290/1302/1285/1283과 새 봇 초기 Elo를 사용했다. 이용자 Elo를 1200으로 고정하고, 각 조건에서 같은 시드 1,000개로 10판씩 추첨했다. 가상 대국 결과에 따른 Elo 갱신은 수행하지 않았다.

이는 통제된 추첨 실험이다. 실제 조사에서 관측한 최근 10판 평균 5.22명과 기준이 다르다. 실제 기록에서는 경기마다 이용자·봇 Elo가 바뀌므로 시뮬레이션의 기존값 3.926명과 일치하지 않는다. 운영에서 평균 8명을 만나게 된다는 보장은 아니다.

## 별도 기보 국면 비교

개발용 탐색에서 사용한 기록을 제외한 6개 대국에서 서로 다른 초반 국면 16개를 선택했다. 원본 기보를 공용 규칙으로 재생하고, 각 국면을 2개 고정 시드로 비교했다.

- 비교 예산: 최대 4,000노드·깊이 4, 5초 시간 상한, 평가 수준 2, 후보 허용폭 48. 실제 14개 봇의 각기 다른 제품 예산과는 구분되는 통제 조건이다.
- 변경 전 선택: 32번, 변경 후 4종 성향의 선택: 128번.
- 즉시 패배를 허용한 선택: 변경 전 0건 / 변경 후 0건.
- 변경 후 불법 수: 0건.
- 변경 후 탐색이 검증한 후보 밖의 선택: 0건.
- 32개 국면·시드 조건 중 16개에서 성향에 따라 선택한 수가 달랐다.
- 호위 배치 수는 진출형 2/32, 호위형 4/32, 측면형 6/32, 전술형 4/32였다. 표본이 작고 다른 특성의 국면이 섞여 있으므로 ‘호위형이 모든 조건에서 호위를 가장 많이 둔다’는 결론은 내리지 않는다.

첫 수의 호위 배치는 현재 탐색의 근접 후보에 들지 않으므로 강제하지 않았다. 대신 동일한 안전한 국면에서 진출형은 왕 전진, 호위형은 왕 곁의 호위 배치, 측면형은 선택한 측면 진출을 하는 사례를 실제 엔진 테스트에 고정했다.

이 검증은 합법성·즉시 전술·관측한 행동 차이를 뒷받침한다. 장기 승률, 초보자 체감 난이도, 사람처럼 느껴지는 정도, 이용자 유지율 향상을 증명하지 않는다.

## 실행한 검사

환경: macOS 로컬, Node 25.9.0, PostgreSQL 16.14. DB 테스트는 별도로 만든 임시 데이터베이스(127.0.0.1)를 사용했다. 운영 DB에는 새 프로필이나 결과를 쓰지 않았다.

- `npm test -- --dir src --maxWorkers=1`: 124개 통과.

- 합계: 서로 다른 테스트 189개 통과. 별도 집중 실행에서 중복으로 통과한 테스트는 더하지 않았다.

로컬 WebSocket 테스트로 대국 생성, 합법 수 처리, 항복·정상 종료, 기보 저장, 매칭 취소를 확인했다. 모바일 실기기나 운영 서버에서 새 패치를 플레이한 검증은 수행하지 않았다.

기보 자료 기준은 [OPENING-STYLES.md](learning/OPENING-STYLES.md)를 따른다. 운영 반영과 앱 버전 변경은 별도 결정 사항이다.
