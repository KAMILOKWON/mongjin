# 1등찍고접기 — 2026-09-20

## 서버 동작

- 영구 ID `ranked-bot-first-place`, 초기 Elo 1600, 전적 0승 0패. 기존 14명을 보존하고 15번째 선수를 추가한다.
- 초기 Elo는 배치값이다. 원본 이용자의 점수나 전적을 복제하지 않으며 동일 실력을 뜻하지 않는다.
- 기보에서 본 국면이면 본인의 수 선택 빈도를 근접 최선수 사이의 선호도로 쓴다. 빈도 비율에 `n/(n+2)`의 표본 신뢰도를 곱한다.
- 공용 AI의 후보 허용폭·탐색 점수·즉시 승리·필수 방어·반복 회피는 변경하지 않는다.
- 없는 국면은 기존 진출형 탐색을 사용한다. 흑백·규칙 설정을 구분하고, 양쪽 수를 섞거나 기록대로 강제 재생하지 않는다.
- 기존 매칭·Elo 갱신·기보 저장·봇의 초반 학습을 그대로 사용한다. 앱 화면과 프로토콜 변경은 없다.

## 자료와 평가

150판 모두 공용 규칙으로 검증했다. 최초 120판의 본인 착수 1,533수, 1,032개 국면만 배포 자료에 포함한다.
흑 60판·백 60판이다. 마지막 30판은 학습에서 제외했다.

평가용 443수 중 166수(37.5%), 초반 12 ply의 180수 중 145수(80.6%)가 학습 자료에 있는 국면이었다.
이는 국면의 일치율이며, 수 선택 재현율이나 승률이 아니다.

평가용 서로 다른 국면 48개(기지 24, 미지 24; 흑 17, 백 31)를 같은 두 시드로 비교했다.
예산은 4,000노드·깊이 4·시간 상한 5초로 고정했다. 현재 제품의 620ms 탐색 예산과 구분한다.

보여주며, 사람 전체 실력의 복제나 체감 향상을 입증하지 않는다. 샘플별 근거는 인접한 JSON 보고서에 있다.

faker·Astra·이겜뭐임과 동일한 축소 예산(1,000노드·깊이 3)으로 흑백 6판을 진행했다.

이 소규모 결과와 축소 예산으로 실제 Elo·장기 승률을 추정하지 않는다.

## 검사 결과

환경: macOS, Node 25.9.0, 로컬 PostgreSQL 16.14. 운영 DB를 테스트에 사용하지 않았다.

- 서버 타입 검사 통과.
- 공용 `src` 80개, `bot` 10개, 임시 Postgres를 포함한 서버 62개 통과.
- 새 WebSocket 통합 검사 1개 추가 통과: 새 봇 매칭, 양쪽 합법 착수, 15수 자연 `goal` 종료,
  양쪽 전적·Elo 갱신, 재시작 후 동일 프로필 보존. 기존 14명의 데이터도 보존했다.
- 서로 다른 테스트 합계 153개. 별도 실행에서 중복 통과한 테스트는 합산하지 않았다.
- 실제 앱 화면 조작은 브라우저 도구가 관리자 보안 정책을 확인하지 못해 차단됐다. 화면·모바일 실기기 검증은 미완료다.
