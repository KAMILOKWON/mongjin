# 초반 성향을 만들 때 쓰는 기보 자료

초반 성향 패치는 별도 모델 학습 없이 기존 탐색이 통과시킨 근접 최선수 사이의 선호도를 조정한다. 사람 기보를 승리 수순으로 그대로 복사하거나 강제 재생하지 않는다.

## 현재 자료로 가능한 작업

2026-09-20 조사 시점 저장 기보는 1,081판이었다. 고정 봇 대국 중 사람이 흑으로 먼저 둔 464판에서는 호위 배치가 171판이었다. 이 171판은 초반 계획을 검토할 후보이며, 171명의 독립된 이용자나 171개의 검증된 정석을 뜻하지 않는다. 사람이 같은 수를 반복한 경우도 포함된다.

`GameRecord`에 이미 있는 규칙 설정·규칙 버전, 진영별 사람/봇 구분, 시작 Elo, 전체 착수, 결과와 종료 이유를 사용한다. 상대 선정 반복 분석에 필요한 계정별 최근 봇 ID는 서버 내부 기록으로 조회한다. 스타일 검증용 기보에 사람 닉네임·인증 정보는 필요 없다.

자료 사용 순서:

1. 공용 규칙으로 기보를 재생하여 불법 수·지원하지 않는 규칙 버전을 제외한다.
2. 사람의 수와 봇의 수를 구분하고, 호위 전개·중앙 진출·측면 진출·상대 진로 차단의 후보 국면을 살핀다.
3. 그 국면에서 대안 수를 같은 탐색 예산으로 비교한다. 승리한 대국의 초반 수라도 상대 실수 덕분일 수 있으므로 결과만으로 정답으로 삼지 않는다.
4. 개발에 쓰지 않은 다른 기보 국면에서 합법성, 즉시 승리 유지, 즉시 패배 방어, 선택 후보의 품질을 비교한다. 한 이용자의 많은 기보가 평가를 독점하지 않도록 계정별·국면별 중복을 고려한다.

## 추가로 있으면 좋은 자료

필수 추가 자료는 없다. 더 분명한 성향을 원할 때 가장 도움이 되는 것은 **수의 의도가 적힌 예시**다.

| 자료 | 필요한 내용 | 용도 |
|---|---|---|
| 스타일별 좋은 예 | 예를 들어 3~5개 국면, 흑·백, 다음 수, 선택 이유 한 줄 | ‘측면형’ 같은 이름이 실제 행동에서 무엇을 뜻하는지 정한다 |
| 같은 계획이 실패한 예 | 2~3개 국면과 실패 이유, 상대의 반격 | 성향보다 전술적 방어가 우선해야 하는 경계를 정한다 |
| 숙련자의 대안 평가 | 같은 국면에서 괜찮은 수와 피해야 하는 수 | 엔진의 평가 편향을 별도로 확인한다 |
| 피드백에 대응하는 기보 | 반복감을 느낀 연속 대국과 어느 순간 그렇게 느꼈는지 | 실제 이용자 체감과 수치의 관계를 살핀다 |

위 수량은 예시를 모으기 위한 시작 규모다. 통계적 충분성이나 실력 향상을 보장하는 기준은 아니다. 사람 대 사람 기보가 더 쌓이면 참고 가치가 높지만, 상대 유형만으로 좋은 기보가 되는 것은 아니다.

## 현재 적용 범위와 한계

- 진출형: 안전한 왕 전진과 중앙 진로를 선호한다.
- 호위형: 왕 곁의 호위 전개와 이미 놓인 호위의 보호를 받는 경로를 선호한다.
- 측면형: 대국 시작 시 선택한 좌·우 방향을 초반 동안 유지한다.
- 전술형: 상대 진로에 놓이는 호위와 해당 진로로 접근하는 수를 선호한다.

성향은 첫 12 ply(흑백 합계 12수)까지만 작동한다. 즉시 승리, 필수 방어, 반복 회피와 기존 탐색의 후보 허용폭이 먼저 적용된다. 성향 때문에 탐색 후보의 허용폭을 넓히지 않는다.

현재 엔진은 초기 국면의 호위 배치를 왕 전진보다 낮게 평가한다. 따라서 첫 수에 호위를 반드시 놓도록 만들지 않았다. 호위형의 차이는 이후 호위 배치가 근접 최선수 후보에 들어오는 국면에서 나타난다. 첫 수의 호위 배치 자체를 목표로 삼으려면 별도 전략 검증이 먼저 필요하다.

행동 차이와 합법성·즉시 전술 회귀를 확인하는 테스트는 `server/openingStyle.test.ts`, `src/ai/move-preference.test.ts`에 있다. 스타일별 장기 승률과 이용자 유지율은 이 테스트로 증명되지 않는다.
