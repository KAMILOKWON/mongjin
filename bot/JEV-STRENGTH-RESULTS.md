# JEV v13 독립 대국 검증

2026-09-20. 사전에 고정한 24판 비교에서 v13은 **10승 2패**, 운영 기준 v9는 **4승 8패**였다. 12쌍 모두 정상 종국으로 완료했고 여섯 배포 기준을 통과했다. 평가 도중 엔진 소스를 바꾸지 않았다.

## 변경 내용

기존 제안이 자주 빠뜨리던 왕의 전진 경로와 호위병의 후속 공격 후보를 보완했다. 후보별로 상대가 왕을 전진시키는 경우와 호위병으로 압박하는 경우의 제한된 수순을 실제 규칙으로 진행하고, 그 결과를 JEV의 최종 판단 자료에 추가했다.

각 수순은 특정 정책에서 나온 조건부 사례이며 강제승 증명이 아니다. 중단된 계산은 미확정으로 표시한다. 최종 JEV가 반환한 수를 그대로 적용하며, 코드의 종합 점수로 선택을 덮어쓰지 않는다. 기보 검증은 선택과 실제 착수의 일치, 합법 수순, 종국 판정, 계산 한도를 확인한다.

## 독립 비교 결과

개발에 사용하지 않은 세 시드 285272317, 309980740, 564847400에서 상대 두 종류와 흑백을 짝지어 비교했다. 버전마다 12판이며 개발용 대국은 이 성적에 포함하지 않았다.

| 상대 / JEV 색 | v9 | v13 |
| --- | --- | --- |
| 연세대MAY / 흑 | 1승 2패 | 1승 2패 |
| 연세대MAY / 백 | 0승 3패 | 3승 0패 |
| うずまき / 흑 | 3승 0패 | 3승 0패 |
| うずまき / 백 | 0승 3패 | 3승 0패 |
| 합계 | 4승 8패 | 10승 2패 |

같은 조건에서 패배가 승리로 바뀐 경우는 6쌍이고, 승리가 패배로 바뀐 경우는 없었다. 두 버전 모두 중단·미완주 0판이다. v13의 백 대국 두 판은 92수에 목적지 도착으로 이겼다.

사전 기준은 후보 최소 8승, 기준 대비 최소 3승 증가, 상대·색 조합마다 최소 1승, 12쌍 완주, 실패 시도 비율 비증가였다. 모두 충족했다. 자세한 판정과 소스 체크섬은 [평가 기록](benchmarks/jev-v13-20260920.json)에 보관한다.

## 안정성과 검증

- v9: 착수 시도 130회 중 실패 6회(4.62%), 시간 초과 3회·HTTP 503 3회.
- v13: 착수 시도 211회 중 실패 5회(2.37%), 시간 초과 4회·HTTP 429 1회.
- 실패한 시도와 재시도를 모두 기록했다. 벤치마크는 수당 재시도 2회, 대국당 총 4회 한도와 30초 대기를 사용했다. 운영의 오류 처리 정책은 변경하지 않았다.
- 로컬 macOS, Node v20.20.2, 순차 실호출. 착수 한도 30초, 수 제한 100수, 수 사이 대기 5초로 양쪽 조건을 맞췄다.
- 성공한 착수의 로컬 지연 p95는 v9 3.134초, v13 7.907초다. 실패·재시도 대기는 이 지연 수치에서 제외되므로 실제 대국의 모든 대기 시간을 뜻하지 않는다.
- 전체 테스트 423개, 별도 서버 테스트 259개(PostgreSQL 포함), 서버 타입 검사와 루트 빌드를 통과했다.
- 실제 운영 이용자·프로필·Elo를 시범대국에 사용하지 않았다. 보고된 JEV 호출 비용은 두 버전 모두 0이다.

## 남은 한계와 운영 범위

MAY 상대 흑은 여전히 1승 2패다. 두 패배에서는 예상한 상대의 전진 경로와 실제 우회 응수가 달랐고, 모델이 유리한 조건부 수순에 기대어 판단했다. 상대의 첫 응수를 더 다양하게 분기하는 개선은 이 평가 뒤의 별도 후보로 검증해야 한다.

이 결과는 작은 고정 실험의 배포 기준 충족을 보여준다. 사람을 상대로 한 승률 우위나 랭킹 1위를 입증하지 않는다. 운영 닉네임은 ‘침착맨이할때까지’, 앱 버전은 1.0.8(64)을 유지하며, 실험 종료는 기존 한국 시간 2026-09-25 00:00이다.
