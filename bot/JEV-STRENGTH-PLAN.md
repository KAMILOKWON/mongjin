# JEV 기력 개선 재검증

2026-09-20. 사용자는 v9의 최종 시범 1승 3패를 개선 완료로 받아들이지 않았고, 실패 국면에서 유효한 대안을 확보한 뒤 독립 조건에서 기력을 비교하는 후속 작업을 승인했다. 이 문서는 결과를 보기 전에 정한 완료 기준이다.

## 범위

- 서버 JEV의 후보 생성·판단 자료를 수정한다. 2단계 JEV + 코드 검증 구조와 최종 모델 ID 그대로 적용 원칙을 유지한다.
- 기존 코드가 찾은 확정 승패와 추정 자료를 분리한다. 더 오래 버티기, 설명 길이, 회귀 테스트 개수를 기력 향상으로 부르지 않는다.
- 운영 프로필·Elo를 변경하는 대국은 하지 않는다. 앱 버전은 앞서 승인한 1.0.8(64)을 유지한다.
- 기력 기준을 통과하기 전에는 후속 수정본을 운영에 배포하지 않는다. 현재 운영 v9는 비교 기준이며 자동 재배포는 없다.

## 원인 분리

개발 자료는 원래 운영 첫 패배와 `v9-heldout-20260921` 네 판이다. 이미 관찰한 이 자료는 이후 독립 검증으로 재사용하지 않는다.

1. 초반 실패 국면에서 모든 합법 수를 조사하여 제안 밖의 유효한 대안이 있는지 확인한다.
2. 대안의 가치를 실제 규칙상 종국 증명과 제한된 상대 정책 아래의 시범 결과로 구분한다. 특정 상대 시뮬레이션의 승리는 강제승이 아니다.
3. 후보와 분석 자료를 고정한 실제 JEV 요청으로 자료 표현이 선택에 영향을 주는지 확인한다. 다른 수를 선택했다는 사실 자체는 개선 증거가 아니다.
4. 후보 생성과 최종 판단 중 문제가 있는 부분만 수정한다. 수순·좌표를 외우게 하거나 종합 코드 점수로 JEV 선택을 덮어쓰지 않는다.

## 배포 후보 선정 기준

기준 버전은 커밋 `1f4eb3cd5d499a596dcc54575d0c7710840edb17`의 v9다. 수정 전 서버 소스를 별도 경로에 동결했다. 시드와 경로는 `artifacts/jev/v10/evaluation-spec.json`에 미리 저장했다.

- 기존 상대 2종(수비형 연세대MAY, 전진형 うずまき), 흑백, 새 시드 3개: 버전당 12판, 합계 24판.
- 동일 상대·색·시드·규칙·착수 예산·실험 재시도 설정을 짝지어 비교한다.
- 후보 버전 12판 중 최소 8승이며, 기준 버전보다 최소 3승 더 많아야 한다.
- 네 상대·색 조합 각각에서 최소 1승을 기록해야 한다.
- 중단·미완주를 승패 분모에서 조용히 빼지 않는다. 12쌍이 모두 정상 종국에 도달하지 못하면 기력 기준 미충족이다.
- 실패한 착수 시도 비율이 기준 버전보다 늘면 통과하지 못한다. 재시도와 429·시간 초과를 별도 보고한다.
- 각 기보와 선택을 canonical rules로 재생해 확인한다. 실제 운영 프로필은 사용하지 않는다.

이것은 작은 실험의 공학적 배포 기준이며 통계적으로 승률 우위를 확정하는 기준은 아니다. 후보 소스를 고정한 후 평가하며, 평가 결과에 맞춰 고친 코드는 그 시드를 개발 자료로 편입하고 새로운 평가가 필요하다. 기준을 사후 완화하지 않는다.

## API와 검증

실호출은 기존 Vercel의 `typesafe-ai/jev`만 사용한다. 기존 기간·비용 확인을 유지하고 다른 유료 모델의 착수로 바꾸지 않는다. API 오류의 로컬 재시도는 기록을 남기는 기존 벤치마크 정책에 한정한다.

서버 전체 테스트(일회용 PostgreSQL 포함), 공통 소스·bot 테스트, 서버 타입 검사와 루트 빌드를 통과한 뒤에도 기력 검증 결과는 별도 판정한다.

입력 표현 검토 근거: [TypeSafe Choice 공식 문서](https://docs.typesafe.ai/primitives/choice). 선택지 이름과 설명은 모델에 전달되며, 질문 ID는 모델에 보이지 않는다. 질문끼리 서로 답을 공유한다고 가정하지 않는다.

## 검증 완료 기록

후보 v13을 고정하고 위 세 시드의 24판을 모두 완료했다. v13 10승 2패, v9 4승 8패로 사전 기준을 모두 충족했다. 구현 내용, 오류·재시도, 남은 약점과 검증 환경은 [결과 보고서](JEV-STRENGTH-RESULTS.md)에 기록했다. 기준과 시드는 결과를 보고 바꾸지 않았다.
